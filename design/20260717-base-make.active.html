Base 镜像补充 Make

创建日期：2026-07-17 所属模块：base image 状态：ACTIVE 基线：slim-v8.5.0 需求来源：Talebook PR #873 CI 兼容性
在精简 base 镜像的最终 base 阶段安装 make，恢复 Talebook CI 执行 Makefile 的能力；Git 经复核不是后端测试依赖，由 Talebook workflow 删除冗余 safe.directory 步骤。不引入 Git、编译器、Qt 或测试框架，不放宽既有 /usr ≤ 400 MiB 门禁。本轮只提交 PR，不发布或覆盖 Docker 标签。

原始诉求与确认边界

Talebook 的 test-server 继续直接使用 talebook/talebook-base:latest 作为 job container，以复用 Calibre 运行环境并避免二次构建测试 target。当前 slim 镜像缺少 git 和 make。复核 CI 日志、workflow 历史、actions/checkout 默认行为及 Makefile 后确认：checkout 在无 Git 时已通过 REST API 下载源码；显式 git config safe.directory 与 checkout 默认行为重复；后端测试目标只真正依赖 make。用户确认采用最小兼容方案。

决策结论
目标分支基于仓库规定的 slim-v8.5.0，不合并或 rebase master。
最终镜像工具只新增 Debian make，使用 --no-install-recommends；不安装 Git。
禁止项继续禁止 gcc、build-essential、Python headers、Qt/PyQt 和 pytest 等测试框架进入最终镜像。
体积预算保持 /usr ≤ 400 MiB；若新增包导致超限，方案保持 WIP，不通过提高门禁规避。
跨仓库配套Talebook workflow 删除显式 Configure Git safe directory；保留 base job container 与既有 Makefile 测试命令。
交付边界本轮完成代码、验证、提交和两个仓库 PR；不发布镜像、不移动现有标签。

实现方案

文件计划改动
Dockerfile在最终 base 阶段单独安装 make 并清理 apt 数据，避免使 runtime-build 与 QuickJS wheel builder 继承兼容工具。
packaging/smoke-test.sh断言 make 存在、可输出版本且 dpkg 状态正常；新增 Git 缺失断言，并继续验证 gcc/build-essential 等禁止项。
design/20260717-base-make.*.html记录依赖复核、体积影响、真实构建和 smoke 结果。

风险、发布与回滚

  • 体积风险：完整 Git 实测会把 /usr 从 345 MiB 增至 435 MiB，因此已排除；make 下载约 452 KiB，仍以最终镜像实测为准。
  • 安全面：不加入 Git 的协议解析和 Perl 运行时；make 采用 Debian 安全仓库版本且禁止 Recommends。
  • 兼容性：保留现有 Calibre 8.5.0、QuickJS、数据库、转换、CJK PDF、无 Qt 与无编译器约束。
  • 发布：本 PR 不触发镜像发布。合并后另行决定何时更新 slim-v8.5.0 与 latest。
  • 回滚：删除最终 base 阶段的 make 安装层并重建即可；没有数据或 API 迁移。

测试结果

验证完成：最小 make-only 方案通过完整构建、镜像 smoke、功能与体积门禁；未发布或覆盖远端镜像标签。
